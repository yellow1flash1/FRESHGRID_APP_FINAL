# FreshGrid demo walkthrough (about 8 minutes)

Use up to **four accounts** (one per role) in different browsers or private windows. All payments are test payments; please don't enter real ID or bank details. A valid test Aadhaar for driver documents is `234123412346`.

## Farmer

1. Open the app → **Farmer** → **Create account** → fill the profile and accept the privacy policy.
2. **Home** shows quick actions, mandi prices and anything in progress. Switch **हिंदी / English** in the top bar.
3. **FasalNiti** → fill "Tell us about your farm" → see the three crop cards and play with the two sliders. The **Example: Rabi benchmark** tab shows the reference scenario.
4. **Home → Scan crate** → choose a crop (Tomato, Potato and Apple are AI-trained) → scan → **List for buyer sale**.
5. **Store/Truck** → book a cold room slot, then book a truck to a mandi.

## Transporter

6. **Transporter** → create account → **Add your vehicle** (type, number, payload, base, radius) → **Verify later**.
7. **Trips** shows the farmer's request. Tap **Accept** → the verification form appears → submit documents → the trip is accepted.
8. **Picked up** → **Mark delivered** → **Pay** → **Got UPI** / **Got cash**.

## Buyer and cold room owner

9. **Buyer** → **Market** → order the farmer's lot into escrow → **My Orders** → confirm delivery with the farmer's 6-digit code (from the farmer's **Money** tab).
10. **Cold room owner** → register a room → check the farmer in with their gate pass number → **Collected / release**.

## Ratings and settings

11. Each side now sees **"Rate N completed deals"**. Rate in 3 taps; ratings unlock when both sides rate (or after 48 hours).
12. Profile icon → your stars and tier → **View**. Try the **Simulator**.
13. Profile icon → **Settings**: theme, text size, read-aloud, notifications, price alerts, download my data.
